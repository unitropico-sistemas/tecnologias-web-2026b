## Síntoma

Qué se observaba exactamente. Mensaje de error literal, código de estado o comportamiento
inesperado. Si otra persona tiene este problema, debe reconocerlo leyendo solo esta sección.

## Causa

Por qué ocurría. No qué se hizo para que dejara de ocurrir: **por qué ocurría**.
Si no logra explicar la causa, la entrada todavía no está lista.

## Solución

Qué se cambió, con el fragmento de código o de configuración mínimo necesario.

```
// código o configuración
```

## Referencia

Enlace a documentación oficial o fuente verificable que respalda la solución.
No sirve un foro sin respaldo ni una respuesta generada por IA sin verificar.

## Notas

Opcional. Variantes del problema, casos en que la solución no aplica, o lo que
todavía queda sin entender.
